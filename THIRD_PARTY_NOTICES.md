# Third-party sources

`lerobot/` and `compat/lerobot_v21/` contain unmodified source snapshots from
Hugging Face LeRobot, https://github.com/huggingface/lerobot, licensed under
Apache License 2.0. Copyright notices remain in the source files; the original
license is included in each directory. Exact commits are recorded in UPSTREAM.json.

Only source and installation metadata are included; upstream media, examples,
documentation, test suites, and Git history are omitted. Runtime dependencies
are installed separately and retain their respective licenses.
